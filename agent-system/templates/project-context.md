# Project Context Template

Use this only when starting or adopting a real project. Copy to an agreed project
documentation location and replace unknowns with confirmed facts. Tell agents
where the resulting document lives through the project's shared instructions.
The coordinator records available context; the user need not fill this template.
Do not treat placeholders as requirements or passing checks. Optional fields below
capture known constraints, not invented gates or project-wide behavioral QA waivers.
