# Task Contract

Keep this concise; it is a packet, not a second project specification.
The coordinator maintains status and ownership. Workers report results. This is
an optional coordinator aid, not a user form: a tiny inline packet is enough.
Questions/read-only analysis need no task packet or task files.

Do not invent invocation IDs, attach stale approvals or put secrets in this record.
Optional specialist N/A reasons may stay in the coordinator's route line instead
of being repeated here. Missing required execution/delegation is BLOCKED, not N/A.
Stop for scope expansion; coordinator reassessment is not permission to expand
user scope or downgrade after a failed gate. User/project gates override minima.
